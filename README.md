# 🚀 AlgoVision-AI
 
An interactive **Data Structures & Algorithms visualizer** built with Streamlit. Watch algorithms run step by step instead of just reading about them. 🧠✨
 
## ✨ Features
 
- 🎬 Step-by-step visualization of core DSA algorithms
- 📄 Multi-page Streamlit interface, one page per topic
- 🎛️ Interactive inputs to experiment with your own data
- 🎨 Clean, beginner-friendly UI
## 📁 Project Structure
 
```
AlgoVision-AI/
├── algorithms/        # 🧮 Algorithm implementations
├── pages/             # 📄 Streamlit pages (one per topic)
├── add.py             # ▶️ App entry point
├── requirements.txt   # 📦 Dependencies
└── README.md
```
 
## ⚡ Getting Started
 
### 1️⃣ Clone the repo
 
```bash
git clone https://github.com/sp3147139-hub/AlgoVision-AI.git
cd AlgoVision-AI
```
 
### 2️⃣ Create a virtual environment (optional)
 
```bash
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # macOS/Linux
```
 
### 3️⃣ Install dependencies
 
```bash
pip install -r requirements.txt
```
 
### 4️⃣ Run the app
 
```bash
streamlit run add.py
```
 
🌐 Then open **http://localhost:8501** in your browser.
